# SECONDE LECTURE — Livres d'occasion

Template e-commerce premium en HTML / CSS / JavaScript pur.

## Concept
"Un bon livre ne devrait pas n'avoir qu'une vie."
Librairie en ligne spécialisée dans les livres d'occasion.

## Fonctions
- Catalogue par genre
- Filtre par état
- Tri par prix / économie
- Recherche
- Favoris avec localStorage
- Panier avec quantités
- Quick view
- Histoire de chaque exemplaire
- Comparaison prix occasion / prix neuf
- Checkout de démonstration
- Estimation de reprise d'un livre
- Newsletter
- Section impact environnemental
- Lucide Icons
- GSAP léger
- Responsive

## Important
Les paiements sont fictifs. Pour une vraie boutique, connecter Stripe/PayPal + backend + gestion de stock.

Ouvrir `index.html`.

Créé comme template de démonstration GioTech Digital.
