# LAGUNE STAYS — Martigues

Template HTML / CSS / JavaScript pur pour hôtel, maisons de vacances ou plateforme locale de réservation.

## Fonctions
- Recherche par zone, dates et voyageurs
- Filtres par type
- Tri par prix / note
- Favoris avec localStorage
- Détails du séjour
- Calcul du nombre de nuits
- Prix total automatique
- Frais de ménage + taxe de séjour fictive
- Checkout de démonstration
- Quartiers de Martigues
- Expériences locales
- Section propriétaires
- Avis
- Contact
- Lucide Icons
- GSAP léger et scroll optimisé

## Utilisation
Ouvrir `index.html`.

Créé comme template de démonstration GioTech Digital.
