# NOVA HABITAT — Real Estate

Template HTML / CSS / JavaScript pur pour agence immobilière.

## Fonctions
- Recherche par ville, type et budget
- Filtres
- Tri par prix
- Favoris avec localStorage
- Fiche détaillée en modal
- Réservation de visite
- Simulateur de mensualité
- Formulaire de contact
- Responsive
- Animations GSAP légères
- Icônes Lucide professionnelles

## Bibliothèques CDN
- Lucide Icons
- GSAP
- ScrollTrigger

## Utilisation
Ouvrir simplement `index.html`.

Créé comme template de démonstration GioTech Digital.
