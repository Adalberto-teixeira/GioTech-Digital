# Martigues Running Festival — Free HTML Template

Template événementiel gratuit créé par GioTech Digital pour démontrer un site complet d'organisation de course à pied.

## Technologies
- HTML5
- CSS3
- JavaScript vanilla
- localStorage pour les interactions de démonstration

## Pages incluses
Accueil, courses, parcours, inscription multi-étapes, participants, résultats, live tracking, programme, infos pratiques, FAQ, bénévoles, partenaires, contact et dashboard administrateur.

## Fonctionnalités démo
- compte à rebours
- inscription multi-étapes
- génération de dossard fictif
- stockage local des inscriptions
- recherche de participants
- résultats et live tracking simulés
- dashboard organisateur
- navigation mobile fixe
- animations et responsive design

## Installation
Aucun build n'est nécessaire. Ouvrez `index.html` ou publiez le dossier sur Cloudflare Workers Static Assets, GitHub Pages, Netlify, Vercel ou tout hébergeur statique.

## Images
Certaines images de démonstration sont chargées depuis Unsplash par URL externe. Elles ne font pas partie du code source. Pour un projet réel, remplacez-les par vos propres images ou vérifiez les conditions d'utilisation du fournisseur.
