# Nova — Personal Portfolio Free Template

Template personnel moderne et responsive créé en HTML, CSS et JavaScript vanilla.

## Contenu
- Hero immersif
- Profil / à propos
- Services
- Portfolio avec modal
- Témoignages de démonstration
- Contact
- Navigation mobile
- Animations au scroll
- Respect de `prefers-reduced-motion`
- Images optimisées en WebP

## Utilisation
Ouvrez simplement `index.html`.

Pour personnaliser :
1. Remplacez le nom, les textes et les liens.
2. Remplacez les images dans `assets/images/`.
3. Modifiez les variables CSS en haut de `assets/css/style.css`.
