# Nexus Journal — Premium Modern Blog / Magazine

Template gratuit premium pour blog moderne, magazine digital, média indépendant ou site éditorial.

## Améliorations
Cette version a été entièrement réécrite en HTML, CSS et JavaScript vanilla. Les images utilisées sont affichées à une taille adaptée à leur résolution originale : elles ne sont jamais agrandies artificiellement pour éviter l'effet flou.

## Pages
- `index.html`
- `article.html`
- `category.html`
- `404.html`

## Fonctionnalités
- Homepage éditoriale premium
- Hero split-layout haute qualité
- Marquee animé
- Cartes et grilles éditoriales
- Photo essay
- Future Lab animé
- Rubriques
- Newsletter avec localStorage
- Recherche instantanée
- Mode clair / sombre
- Article long format avec barre de lecture
- Rubrique avec filtres et tri
- Navigation mobile fixe
- Animations de scroll
- Glow interactif desktop
- Responsive complet
- `prefers-reduced-motion`
- Images WebP haute qualité
- Aucun framework
- Aucun build obligatoire
