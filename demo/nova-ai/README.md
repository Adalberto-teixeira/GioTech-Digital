# Nova AI Institute — Free HTML Template

Template gratuit pour une académie d'intelligence artificielle, un centre de formation ou une agence IA.

## Concept
Le projet combine :
- formations IA,
- automatisation,
- conseil,
- cas d'usage,
- mentors,
- FAQ,
- formulaire de contact de démonstration.

## Technologies
- HTML5
- CSS3
- JavaScript vanilla
- Aucun framework
- Aucun build obligatoire

## Fonctionnalités
- Responsive mobile-first
- Animations au scroll
- Hero animé
- Cartes de formations
- Modal de programme
- FAQ accordéon
- Formulaire de démonstration avec localStorage
- Navigation mobile fixe
- `prefers-reduced-motion`
- Images optimisées au format WebP

## Utilisation
Ouvrez `index.html` dans un navigateur ou publiez le dossier sur Cloudflare Workers Static Assets, GitHub Pages, Netlify ou un hébergement statique.

## Personnalisation
Modifiez :
- le nom Nova AI Institute,
- les formations,
- les couleurs dans `assets/css/style.css`,
- les images dans `assets/images/`,
- les coordonnées et liens.
