# LINA VEGA — Mobile Artist Template

Template français mobile-first pour artiste / chanteuse / groupe.

## Deux expériences
- `index.html` : page de présentation GioTech Digital avec téléphone interactif (iframe)
- `artist.html` : site complet de l'artiste, utilisable directement

## Fonctions
- Accueil artiste
- Agenda de spectacles
- Filtres France / Europe
- Achat de billets (démo)
- Choix de catégorie et quantité
- Music Store
- Singles et album à vendre
- Pré-écoute simulée
- Panier localStorage
- Checkout de démonstration
- Biographie
- Fan club / newsletter
- Navigation mobile fixe
- Drawer menu / panier
- Responsive desktop/tablette/mobile

## Visuels
Les illustrations SVG (portrait fictif, pochettes et affiches) ont été créées spécialement pour cette démo et ne dépendent pas des images du template ThemeForest.

## Important
Le paiement et l'audio sont simulés. Pour une vraie boutique, connecter Stripe/PayPal et des fichiers audio ou une plateforme de streaming.
