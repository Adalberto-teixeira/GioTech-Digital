# Luméa Clean — Premium Cleaning Free Template

Template gratuit pour entreprise de nettoyage, ménage à domicile, bureaux, locations courte durée et services d'entretien.

## Refonte
Cette version a été développée avec une nouvelle architecture HTML/CSS/JavaScript, sans reprendre les composants JavaScript, Bootstrap ou la structure du template de référence.

## Fonctionnalités
- Hero responsive
- Estimateur rapide
- Cartes de services
- Parcours de réservation
- Mockup mobile
- Comparateur avant / après
- Estimateur complet avec calcul dynamique
- Formulaire de démonstration stocké dans localStorage
- FAQ accordéon
- Avis de démonstration
- Blog / contenu SEO
- Navigation mobile fixe
- Animations au scroll
- Respect de prefers-reduced-motion
- Images WebP optimisées
- Aucun framework
- Aucun build nécessaire

## Utilisation
Ouvrez `index.html`.

Le projet peut être hébergé sur Cloudflare Workers Static Assets, GitHub Pages, Netlify ou n'importe quel hébergement statique.

## Important
Les prix, avis, profils et données affichés sont fictifs et servent uniquement à la démonstration.
