# SOLIDAIRE — Association Locale

Template HTML / CSS / JavaScript pur pour association, ONG, club local ou organisation solidaire.

## Fonctions
- Présentation de la mission
- Actions / projets
- Chiffres d'impact
- Agenda d'événements
- Inscription à un événement
- Formulaire bénévole
- Simulation de dons
- Partenaires
- Témoignage
- Contact
- Lucide Icons
- GSAP léger
- Responsive

## Utilisation
Ouvrir `index.html`.

Créé comme template de démonstration GioTech Digital.
