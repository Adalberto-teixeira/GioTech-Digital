# Atelier Nail — Mobile Booking Template

Template mobile-first en français pour prothésiste ongulaire, manicure ou institut.

## Pages / vues
- Accueil
- Services & prix
- Réservation
- Galerie
- Mes rendez-vous

## Fonctions
- Disponibilités sur 7 jours
- Créneaux interactifs
- Choix du service
- Résumé prix/date/heure
- Formulaire de réservation
- Rendez-vous sauvegardés en localStorage
- Annulation de rendez-vous
- Favoris galerie
- Présentation GioTech avec téléphone interactif
- Scrollbar masquée sur le site mobile

## Important
La disponibilité est simulée côté JavaScript. Pour une vraie activité, connecter les créneaux à Supabase/Firebase ou un backend/calendrier.
