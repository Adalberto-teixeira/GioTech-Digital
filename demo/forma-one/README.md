# FORMA/ONE — Premium Education & Formation Template

Template gratuit premium pour école digitale, centre de formation, plateforme e-learning ou organisme de reconversion.

## Fonctionnalités
- Hero interactif type espace apprenant
- Header desktop premium + navigation mobile
- 3 parcours de formation
- Catalogue de cours avec filtres et tri
- Timeline horizontale GSAP / ScrollTrigger
- Project Lab
- Mentors
- Quiz interactif avec XP
- Tarifs
- FAQ
- Modal d'inscription
- Espace apprenant latéral
- LocalStorage
- Mode clair / sombre
- Responsive complet
- Animations GSAP
- prefers-reduced-motion

## Technologies
HTML5, CSS3, JavaScript vanilla, GSAP + ScrollTrigger via CDN.
