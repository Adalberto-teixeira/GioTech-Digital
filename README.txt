Landing Express — Template gratuit par GioTech Digital
========================================================

13 pages prêtes à l'emploi, dans un seul fichier interactif :
404, Bientôt en ligne, Merci, Maintenance, Link-in-bio,
Landing entreprise, Événement, Page produit, Menu digital,
Contact professionnel, CV simple, Artiste, Mariage.

Comment l'utiliser
------------------
1. Ouvrez index.html dans votre navigateur pour voir toutes les pages.
2. Chaque page vit dans son propre "onglet" (voir le fichier index.html,
   section <div class="page-view" data-page="...">) — copiez le bloc qui
   vous intéresse dans votre propre projet.
3. Les styles sont dans style.css, organisés par page (cherchez les
   commentaires /* ---------- Nom de la page ---------- */).
4. Aucune dépendance obligatoire — HTML/CSS/JS natifs. GSAP est chargé
   par CDN uniquement pour les petites animations ; vous pouvez le
   retirer sans rien casser.
