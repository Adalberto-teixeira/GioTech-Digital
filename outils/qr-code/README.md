Générateur de QR Code autonome en HTML/CSS/JS.

Types : URL, texte, e-mail, téléphone, Wi-Fi, contact vCard.
Options : couleurs, taille, logo, texte SCANNEZ-MOI, PNG et SVG.

Note : qrcodejs est chargé via CDN, donc une connexion internet est nécessaire pour la bibliothèque QR lors de l'ouverture de la page.
